## Overview

I wanted to learn to code an FTC robot in Java rather than blocks, so I did it the direct way — build the whole thing and find out what breaks.

The repository holds a competition-ready robot: drivetrain, subsystems, and autonomous routines. It is also the clearest record of what I understood about Java at the time.
